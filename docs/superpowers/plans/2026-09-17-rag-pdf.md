# PDF RAG Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Add a private Documents screen where a Pulso user uploads a selectable-text PDF and asks Groq cited questions about it.

**Architecture:** FastAPI validates and stores uploads privately, extracts text by page with pypdf, persists bounded chunks, and lexically ranks the relevant chunks for Groq. Vue calls authenticated document endpoints using FormData without JSON content type.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy 2, Pydantic 2, pypdf, Groq SDK, Vue 3, TypeScript, Vitest, pytest.

**Spec:** docs/superpowers/specs/2026-09-17-rag-pdf-design.md

## Global Constraints

- Every document and chunk query filters by authenticated user_id.
- Store files only below DOCUMENT_STORAGE_PATH, never in frontend assets.
- Permit application/pdf with .pdf suffix, a 10 MiB maximum and 100-page maximum.
- PDFs without selectable text fail locally; OCR is excluded.
- Allow 1-4,000 character questions and cap Groq context at six chunks and 18,000 characters.
- Write and observe every regression test fail before its implementation.
